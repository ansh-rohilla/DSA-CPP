# DSA + CPP 🚀

A comprehensive collection of Data Structures and Algorithms implementations in C++, designed for learning, practice, and interview preparation.

## 📁 Folder Structure

This repository is organized into the following main categories:

### 🌳 **Trees**
- **Binary Trees** - Fundamental tree operations, traversals, and advanced algorithms
- **BST (Binary Search Trees)** - Search, insertion, deletion, and balancing operations

### 📊 **Arrays & Matrices**
- **2D Arrays** - Matrix operations, pattern printing, and 2D problem solving

### 🔗 **Linear Data Structures**
- **LinkedList and Stack** - Singly/doubly linked lists, stack implementations and applications
- **Queue** - Queue implementations, circular queues, and priority queues

### 🧮 **Mathematics**
- **Maths for DSA** - Mathematical concepts essential for algorithmic problem solving

### 🔀 **Sorting & Searching**
- **Sorting Algorithms** - Implementation of various sorting techniques from basic to advanced

### 🌐 **Graphs**
- **Graphs** - Graph representations, traversals (BFS, DFS), shortest path algorithms, and more

### 📦 **Advanced Data Structures**
- **Heaps** - Min-heap, max-heap implementations and heap-based algorithms
- **C++ STL** - Standard Template Library usage and custom implementations

### 🔤 **String Algorithms**
- **Strings** - String manipulation, pattern matching, and algorithmic problems

### 🤖 **Machine Learning**
- **kmeans from scratch** - Implementation of K-means clustering algorithm

## 🛠️ Technologies Used

- **Language**: C++
- **Compiler**: GCC/G++
- **IDE**: VS Code
- **Version Control**: Git

## 🚀 Getting Started

### Prerequisites
- C++ compiler (GCC/G++ recommended)
- Text editor or IDE (VS Code recommended)
- Git for version control

### Installation
1. Clone the repository:
```bash
git clone https://github.com/ansh-rohilla/DSA-CPP.git
cd DSA-CPP
```

2. Compile any C++ file:
```bash
g++ -o program filename.cpp
./program
```

## 📚 Learning Path

1. **Start with Basics**: Begin with arrays, strings, and basic mathematics
2. **Move to Linear Structures**: Learn linked lists, stacks, and queues
3. **Advance to Trees**: Master binary trees and BSTs
4. **Explore Graphs**: Understand graph algorithms and applications
5. **Master Algorithms**: Study sorting, searching, and advanced algorithms
6. **Practice**: Solve problems from each category

- ✅ **Well-commented Code**: Each implementation includes detailed explanations
